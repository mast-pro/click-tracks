# Click & Slate

A MAST Productions tool for music-video playback tracks. Drop in a song and it adds:

- a "camera rolling" call, then "set"
- a count-in click locked to the song's tempo, which can carry on into the song
- clicks over the ending and a "cut" call
- export as MP3 (default: 44.1 kHz, 192 kbps) or WAV

Everything runs in the browser. Tracks never leave the user's computer, and the page works offline once loaded.

**Live site:** https://rickyd-lab.github.io/click-and-slate/

To update the site, replace `index.html` and commit to `main`. GitHub Pages republishes within a minute or two.
